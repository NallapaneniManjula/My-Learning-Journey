# Longest Substring Without Repeating Characters

## Background
This problem was assigned as part of my college's daily technical coding assessment. It is included in my **My Learning Journey** repository to document my progress in problem-solving and Data Structures & Algorithms (DSA).

## Problem Statement
Given a string `s`, determine the length of the longest substring without repeating characters.

## Approach
This solution uses a **brute-force approach**.
- Iterate through each character as the starting point.
- Build a substring containing unique characters.
- Stop when a duplicate character is encountered.
- Track the maximum length obtained across all starting positions.

## Complexity Analysis

| Metric | Complexity |
|--------|------------|
| **Time Complexity** | O(n²) |
| **Space Complexity** | O(n) |
